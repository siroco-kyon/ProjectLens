# 関連ファイルの範囲指定：実装プラン

## 目的

選択機能の資料は、これまで参照元・参照先を一段だけ補足していました。処理の理解には参照先、変更の影響候補の確認には参照元を調べたい一方、小さい資料を作るために選択対象だけへ絞る場合もあります。この用途に合わせて、補足の方向と最大段数を利用者が指定できるようにします。

既存の構文解析結果を利用でき、追加パッケージや対象プロジェクトの実行は不要です。意味解析、プリプロセッサシンボルの指定、依存グラフの可視化は別の拡張候補として残します。

## 仕様と実装順序

1. Core の生成条件に、選択のみ・参照先・参照元・両方向と最大1〜3段を追加します。初期値は既存と同じ両方向・1段です。
2. 解析済みファイルだけを関係の方向に沿って幅優先でたどります。選択ファイル・型の定義ファイルを出発点とし、最短段数を記録します。循環・重複・複数の出発点を扱い、未解析の端点を経由しません。パスの区切り文字と大文字小文字を統一して比較します。
3. 資料の対象範囲に方向・段数・選択数・補足数を記載し、明示選択と自動補足を一覧で示します。選択機能の関係表は両端が資料の範囲にある行へ限定します。プロジェクト構成・参照宣言は従来の全体情報を維持します。
4. WPF の C の資料設定に方向・段数を追加します。選択のみでは段数を無効化し、条件変更後はプレビュー・コピー・保存を無効化します。
5. 回帰テストと WPF 起動検証を実行し、利用ガイド・検証記録を更新します。レビュー後に PR を作成し、検証結果を確認して main へマージします。

## 維持する条件

補足するのは構造情報です。本文は有効化したうえで明示選択した定義ファイルだけを含めます。資料生成時にファイルを読み直しません。推定の関連は意味的な依存関係や変更の影響の確定情報として扱いません。概要・構造一覧の生成範囲は関連補足の設定で変わりません。

## 検証

方向と段数による境界、循環、重複、複数選択、未解析端点、パス正規化、partial 型選択、ソース本文の限定、範囲外の関係行の除外、不正な条件、キャンセルを回帰テストで確認します。Release ビルドと既存テストに加え、WPF で生成・条件変更時の無効化・再生成を検証し、サンプル画面で配置を確認します。実施結果は [検証記録](VERIFICATION.md) に追記します。
